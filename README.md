# 🌤️ Sky Reading — Modern Ambient Weather Dashboard

Sky Reading is a minimal weather web application that dynamically changes its visual appearance (sky gradients, sun/moon positioning, and starfields) based on current weather conditions and time of day.

## ✨ Key Features

* **Dynamic Atmospheric UI**: Background gradients adapt to weather conditions (clear, overcast, rain, snow, storm, fog) and smoothly transition between day and night.
* **Celestial Motion**: Sun and moon position shifts dynamically based on local time.
* **Live Search & Geolocation**: Instant city lookup powered by Open-Meteo Geocoding API, plus optional location lookup via browser geolocation.
* **Forecast Details**: Displays current conditions, humidity, wind speed, sunrise/sunset, a 12-hour forecast, and a 7-day extended outlook.
* **Unit Switching**: Toggle seamlessly between Fahrenheit (°F) and Celsius (°C).

---

## 🛠️ Built With

* **Frontend**: Pure HTML5, CSS3 (CSS Variables & Glassmorphism design), Vanilla JS (ES6+)
* **APIs Used**: [Open-Meteo Forecast API](https://open-meteo.com/) (No API key required)
* **Typography**: IBM Plex Sans, IBM Plex Mono, and Fraunces via Google Fonts
